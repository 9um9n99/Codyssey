# 조각조각 🥒

**목표를 입력하면 AI가 실행 순서가 있는 작은 단계로 나눠주고, 달력에서 하나씩 체크하며 끝까지 진행할 수 있는 웹 서비스**

👉 **[https://zogak-zogak.vercel.app](https://zogak-zogak.vercel.app)** (로그인 없이 바로 사용)

Codyssey "AI 웹 개발" 미션으로 만들었어요.

---

## 한눈에 보기

"포트폴리오 만들기", "이사 준비하기"처럼 큰 목표는 **어디서부터 시작할지** 몰라서 미루게 돼요.
조각조각은 이 문제를 세 단계로 풀어요.

| 단계 | 화면 | 하는 일 |
| --- | --- | --- |
| ① 나누기 | **조각내기** | 목표와 기한을 입력하면 AI가 "지금 당장 할 수 있는 행동" 단위로 나눠줘요. |
| ② 실행하기 | **조리하기** | 달력에 일정이 잡히고, 오늘 할 일을 체크하며 진행해요. |
| ③ 기록하기 | **나의요리** | 목표를 끝내면 요리 한 접시가 완성되고, 레시피북(도감)에 모여요. |

> 서비스 이름이 "오이"인 이유: 큰 목표를 통오이 한 개로 보고, AI(보조셰프 **조각이**)가 이걸 조각조각 써는 콘셉트예요. 그래서 나뉜 단계를 "조각", 목표를 끝내는 걸 "요리 완성"이라고 불러요.

---

## 사용 방법

1. **목표 입력** — 첫 화면에 목표를 적고 기한(며칠 안에 끝낼지)을 정해요.
2. **결과 확인** — AI가 나눈 단계가 나와요. 마음에 안 드는 단계는 고치거나 지우고, 직접 추가할 수도 있어요. 단계마다 며칠 차에 할지도 정할 수 있어요.
3. **요리하러 가기** — 누르면 달력에 일정이 저장돼요.
4. **체크하기** — 조리하기 화면에서 끝낸 단계를 체크해요. 모두 체크하면 요리가 완성돼요.
5. **레시피북 보기** — 나의요리에서 지금까지 완성한 요리를 확인해요.

---

## 주요 기능

### 조각내기 (첫 화면)
- 목표(최대 120자)와 기한(1~90일)을 입력해요. 기한은 일수 또는 시작일~종료일로 정할 수 있어요.
- **파일·이미지 첨부(선택)**: 현재 상황이 담긴 스크린샷이나 메모(이미지, PDF, txt, md, csv)를 최대 3개 올리면, AI가 그 내용을 읽고 이미 끝낸 일은 빼고 나눠줘요.
- 결과 화면에서 단계 **수정·삭제·추가**와 **며칠 차에 할지** 조정이 가능해요.

### 조리하기
- **오늘 할 조각**: 목표가 여러 개여도 각 목표의 "지금 차례인 단계"만 모아서 보여줘요. 기한이 지난 것이 먼저, 그다음 우선순위 순이에요.
- **달력**: 목표마다 다른 색 막대로 일정이 표시돼요.
- **목표별 진행 현황**: 단계 체크, 목표 이름·단계 내용 수정, 목표 우선순위(높음·보통·낮음) 설정이 가능해요.

### 나의요리
- 완성한 목표가 요리 카드로 쌓이고, 누르면 레시피북의 해당 페이지가 열려요.
- **레시피북**은 오이 요리 25종을 모으는 도감이에요. 아직 못 모은 요리는 `？`로 잠겨 있어요.
- 그중 3종(오이후무스·오이라따뚜이·오이파스타)은 나올 확률이 낮은 **희귀 요리**예요.

## AI는 어떻게 목표를 나누나요?

```
브라우저 ──(목표·기한·첨부)──▶ 서버리스 함수(api/chop.py) ──▶ Claude(Codyssey API)
   ▲                                  │
   └────────── 단계 목록(JSON) ◀───────┘
```

1. 브라우저가 `POST /api/chop`으로 목표와 기한(과 첨부)을 보내요.
2. 서버 함수가 Claude를 호출해요. **API 키는 서버 환경 변수에만 있고 브라우저로 내려가지 않아요.**
3. Claude는 목표의 성격(디자인, 이사, 공부, 운동 등)을 스스로 판단해서 알맞은 흐름으로 나눠요. 각 단계는 "경쟁 서비스 3곳 리서치하기"처럼 **구체적인 행동 하나**로 쓰도록 지시했어요.
4. 단계 수는 기한에 비례해요. (1~3일: 2~3개 / 4~9일: 4~6개 / 10~20일: 7~9개 / 21일 이상: 10개)
5. 실패하면(서버 연결 불가, 시간 초과, 키 오류, 사용량 한도, 응답 형식 오류) 이유를 화면에 알려주고 다시 시도할 수 있어요.

## 기술 스택

| 구분 | 사용한 것 |
| --- | --- |
| 프론트엔드 | 순수 HTML / CSS / JavaScript (프레임워크 없음) |
| 백엔드 | Vercel Serverless Function (Python) — `api/chop.py` |
| AI | Codyssey 공개 API 콘솔의 Anthropic 호환 API (`claude-sonnet-4`) |
| 데이터 저장 | 브라우저 `localStorage` (서버 DB 없음) |
| 배포 | GitHub → Vercel |

> ⚠️ 데이터는 사용 중인 **브라우저에만** 저장돼요. 다른 기기·다른 브라우저에서는 보이지 않고, 사이트 데이터를 지우면 기록도 사라져요.

## 직접 실행해보기

**준비물**: Node.js, Python 3, Codyssey 공개 API 콘솔에서 발급받은 API 키

**1) 환경 변수** — 프로젝트 폴더에 `.env` 파일을 만들고 두 줄을 적어요. (`.gitignore`에 들어 있어 GitHub에 올라가지 않아요.)

```
ANTHROPIC_API_KEY=발급받은_키
ANTHROPIC_BASE_URL=https://copa.codyssey.kr
```

**2) 실행**

```bash
npx vercel dev
```

브라우저에서 **http://localhost:3000** 으로 열어요.
(`index.html`을 더블클릭해서 열면 AI 호출이 동작하지 않아요.)

---

## 배포 방법 (Vercel)

1. 이 폴더를 GitHub에 push해요.
2. Vercel에서 저장소를 Import해요. 프로젝트가 저장소 안의 하위 폴더라면 **Root Directory**를 그 폴더(`AI-Native-Advance/A1-3-ai-web-service`)로 지정하고, Framework Preset은 `Other`로 둬요.
3. **Settings → Environment Variables**에 위 환경 변수 2개를 등록해요.
4. Deploy해요. 환경 변수를 나중에 바꿨다면 **Redeploy**해야 반영돼요.
