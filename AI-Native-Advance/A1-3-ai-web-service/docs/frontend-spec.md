# 조각조각 — 프론트엔드 설명서

화면·파일·데이터 구조를 한 곳에 정리한 문서입니다. 수정할 부분을 "몇 번 항목의 무엇"처럼 짚어 말할 때 쓰세요.

## 0. 구조

```
index.html      조각내기 (첫 화면)
calendar.html   조리하기
record.html     나의요리
css/style.css   전체 스타일 (파일 아래쪽 THEME 블록이 위쪽 규칙을 덮어씀)
js/main.js      공통: 계획 저장·불러오기, 요리 25종 데이터, 요리 뽑기, 완성 축하
js/index.js     첫 화면 보조 효과(열고 닫기, 스크롤 등장)
js/cutting.js   조각내기 화면 로직
js/calendar.js  조리하기 화면 로직
js/record.js    나의요리 화면 로직
api/chop.py     AI 호출 서버리스 함수
```
상단 메뉴(모든 화면 공통): 조각내기 · 조리하기 · 나의요리

## 1. 디자인 기준
- **색**: 배경 `#EEF4DF`, 카드 `#FFFEF8`, 진초록 `#2B7046`/`#1B4430`, 연두(씨) `#D8EA6B`, 꿀빛 안내 `#F8EBC4`, 토마토(행동 버튼·경고) `#D6401F`, 글자 `#1D2B21`
- **글꼴**: 제목 Jua(굵게 하지 않음), 본문 Pretendard. 한글 줄바꿈은 `word-break: keep-all`.
- **위계**: 페이지 제목(2.1rem) > 패널 제목(1.4rem) > 소제목 > 본문(1rem) > 보조(0.8125rem 이상)
- **반응형**: 560px 이하는 모바일 배치. 가로 스크롤이 생기지 않도록 확인.

## 2. 조각내기 (`index.html`, `js/cutting.js`)
1. **히어로**: 상단 반원 오이 안에 제목·설명·"사용법 보기"(팝업). 아래에 입력 카드가 이어짐.
2. **입력 폼**: 목표(120자) → 파일·이미지 첨부 → 팁(접힘) → 기한(−/숫자/+, 1~90일로 자동 보정) → 날짜로 정하기(시작일~종료일) → 제출.
3. **로딩 / 오류**: AI 응답을 기다리는 동안 로딩, 실패하면 이유와 "다시 시도하기".
4. **결과**: 만들어질 요리, 단계 목록(번호 · 내용 · ✎ 수정 · 🗑 삭제 · 며칠 차), "조각 직접 추가하기", "요리하러 가기", "다른 목표 썰기".
5. **임시 저장**: 결과는 "요리하러 가기"를 누를 때만 계획으로 저장됨. 그 전에는 이 탭의 `sessionStorage(jogak-draft)`에만 있어서 새로고침해도 복원되고, 쓰지 않고 떠나도 조리하기에 남지 않음.
6. **첨부**: 이미지는 브라우저에서 줄여서(최대 1280px) 보내고, PDF는 pdf.js로 글을 읽어서 보냄. 최대 3개.

## 3. 조리하기 (`calendar.html`, `js/calendar.js`)
1. **오늘 할 조각**: 목표마다 첫 미완료 단계를 모아 보여줌. 정렬: 기한 지남 → 우선순위 → 기한 순, 최대 3개. 체크하면 바로 반영.
2. **달력**: 월 이동, 오늘 표시, 목표별 색 막대. 처음엔 이번 달(걸친 계획이 없으면 곧 시작할 계획의 달)로 열림.
3. **목표별 진행 현황**: 카드(목표명 ✎ · 우선순위 · 요리 · 일수 · 진행 n/m) → 펼치면 단계 체크리스트(✎ 내용 수정). 편집 모드에서 계획 삭제.
4. 체크할 때 스크롤 위치와 포커스를 유지(다시 그려도 화면이 튀지 않음).
5. 마지막 단계를 체크하면 완성 축하 → 나의요리로 이동.

## 4. 나의요리 (`record.html`, `js/record.js`)
1. 진행 중인 계획이 있으면 "조리하기에서 이어가기" 띠 표시.
2. **완성한 요리** 카드 목록(최근 순). 누르면 레시피북의 해당 요리 페이지로 열림.
3. **레시피북**: 표지 → 목차(25칸, 페이지 이동) → 요리 상세(사진, 설명, 만든 기록, 이전/다음). 한 번 펼쳐본 뒤에는 펼친 채로 시작(`jogak-book-opened`).

## 5. 데이터 구조
저장 위치: `localStorage` 키 `jogak-plans` (배열). 읽을 때 깨진 데이터는 걸러냄.

```json
{
  "id": "고유 ID",
  "goal": "목표 이름",
  "totalDays": 7,
  "dish": "오이무침",
  "createdAt": "시작일 ISO 문자열",
  "completedAt": null,
  "priority": "high | mid | low (없으면 mid)",
  "pieces": [{ "title": "단계 내용", "done": false, "day": 0 }]
}
```
- `day`는 시작일 기준 0부터 시작하는 일차, 화면에는 +1해서 "n일차"로 표시.
- 완성 여부 = `pieces`가 1개 이상이고 모두 `done`. (`isPlanComplete`)
- 그 밖의 키: `jogak-draft`(sessionStorage, 결과 화면 임시 보관), `jogak-book-opened`(레시피북 펼침 기억).

## 6. 서버 API (`api/chop.py`)
- `POST /api/chop` — 요청 `{ goal, days, attachments? }`, 응답 `{ pieces: [{ title }], notice? }`
- 환경 변수: `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL`
