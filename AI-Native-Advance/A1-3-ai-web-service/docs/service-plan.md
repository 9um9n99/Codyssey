# 서비스 기획서 — 조각조각 🥒

## 1. 만든 이유
"포트폴리오 만들어야 하는데", "이사 준비해야 하는데" — 할 일은 분명한데 **어디서부터 시작할지 몰라** 미루게 됩니다.
조각조각은 막막한 목표를 AI가 **순서가 있는 구체적인 행동**으로 나눠주고, 끝낼 때마다 진행 상황이 쌓이다가 목표를 모두 끝내면 오이 요리가 완성되는 보상을 줘서 끝까지 가도록 돕습니다.

## 2. 타겟 사용자
- 큰 목표(포트폴리오, 시험, 이사, 프로젝트)를 앞두고 시작을 못 하는 사람
- 여러 목표를 동시에 진행하며 "오늘 뭘 해야 하는지"를 한눈에 보고 싶은 사람

## 3. 사용 흐름
조각내기(목표 입력 → AI가 단계로 나눔 → 수정) → 조리하기(달력에서 오늘 할 일 체크) → 나의요리(완성한 요리 수집)

| 화면 | 역할 |
| --- | --- |
| 조각내기 (홈) | 목표·기한 입력, 파일/이미지 첨부, AI 결과 확인과 수정(단계 수정·삭제·추가, 며칠 차에 할지 조정) |
| 조리하기 | 오늘 할 조각, 월간 달력, 목표별 진행 현황, 체크, 목표 우선순위 |
| 나의요리 | 완성한 요리 목록, 25종 레시피북(도감) |

## 4. 핵심 기능
1. **AI 조각내기**: 목표의 성격을 판단해 기한에 비례한 개수(최대 12개)의 구체적인 행동으로 분해. 현재 상황이 담긴 이미지·PDF·텍스트를 첨부하면 이미 끝난 일은 빼고 나눔.
2. **일정 배치**: 단계마다 "며칠 차에 할지"를 정하면 달력에 목표별 색 막대로 표시.
3. **오늘 할 조각**: 단계는 순서대로 진행해야 하므로, 목표마다 "지금 차례인 단계" 하나만 모아서 보여줌(기한 지난 것 → 우선순위 → 기한 순, 최대 3개).
4. **목표 우선순위**: 높음·보통·낮음은 **목표 단위로만** 지정. 단계에는 순서가 있어서 단계별 우선순위는 두지 않음.
5. **진행 체크 · 완성**: 모든 단계를 체크하면 축하 화면과 함께 요리 완성, 되돌리면 진행 중으로 복귀.
6. **레시피북**: 오이 요리 25종 도감. 희귀 요리 3종(오이후무스·오이라따뚜이·오이파스타)은 일반 요리의 약 30% 확률. 아직 못 모은 요리 중에서 먼저 뽑아 중복을 막음.

## 5. AI 기능 기준
- **입력**: `goal`(비어 있으면 안 됨), `days`(1~90 정수), `attachments`(선택, 이미지·텍스트)
- **처리**: 목표 성격 판단 → 논리 순서 → "구체적인 행동 하나" 문장. 개수 규칙은 1~3일 2~3개 / 4~9일 4~6개 / 10~20일 7~9개 / 21일 이상 10개.
- **출력**: 순수 JSON 배열 `[{"title": "..."}]` (코드블록·설명 없이). 서버가 코드블록으로 감싸진 응답이나 앞뒤 글이 섞인 응답에서도 배열을 추출.
- **실패 처리**: 잘못된 입력은 400, 키/주소 누락은 500, 외부 API 오류는 502(원인 상태 코드 포함). 화면은 연결 실패·시간 초과(25초, 첨부 시 40초)·키 오류·사용량 한도·형식 오류를 각각 안내하고 다시 시도 버튼을 제공. 이미지를 읽지 못하면 글만으로 한 번 더 시도.
- **보정**: 화면에서 빈 제목·글자가 아닌 제목은 걸러내고, 한 번에 12개까지만 받음.
- **보안**: API 키는 서버 환경 변수에만 존재하고 브라우저로 전달되지 않음.

## 6. 데이터
서버 DB 없이 브라우저 `localStorage`의 `jogak-plans` 하나로 목표와 단계를 모두 관리합니다. 완성 여부는 저장하지 않고 "모든 단계가 체크됐는지"로 그때그때 계산합니다. (한계: 기기·브라우저 간 동기화 없음)

## 7. 기술 구성
순수 HTML/CSS/JS + Vercel Serverless(Python) + Codyssey 공개 API(`claude-sonnet-4`), GitHub 연동 자동 배포.
