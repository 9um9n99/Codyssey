# 서비스 기획서 — 조각조각 🥒

## 1. 만든 이유 / 목적
"포트폴리오 만들어야 하는데", "이사 준비해야 하는데" — 할 일은 분명한데 어디서부터 시작할지 몰라 미루게 됩니다.
조각조각은 막막한 목표를 AI가 **논리적인 순서의 구체적 행동**으로 쪼개주고, 끝낼 때마다 오이 요리가 완성되는 보상을 줘서 끝까지 가게 돕습니다.

## 2. 타겟 사용자
- 큰 목표(포트폴리오, 시험, 이사, 프로젝트)를 앞두고 시작을 못 하는 사람
- 여러 목표를 동시에 진행하며 일정을 눈으로 보고 싶은 사람

## 3. 페이지 구성
| 페이지 | 역할 |
| --- | --- |
| 조각내기 (홈) | 목표/기한 입력, AI 조각 결과 확인, 조각별 일수 수정 + 하단에 서비스 컨셉·사용법 안내 |
| 조리하기 | 캘린더 + 목표별 진행 현황, 조각 체크 |
| 나의요리 | 완성·진행 중 목록, 체크리스트, 레시피북(도감) |

## 4. 핵심 기능
1. AI 조각내기: 목표의 성격을 판단해 기한에 비례한 개수(2~10개)의 단계로 분해
2. 일정 배치: 조각마다 일수를 조정하면 캘린더에 한 줄 막대로 표시
3. 진행 체크: 조각 체크 → 모두 체크하면 완성 축하 팝업 + 요리 기록
4. 레시피북: 25가지 요리를 번호 도감으로 수집, 레어 요리 3종(오이후무스·오이라따뚜이·오이파스타)은 낮은 확률로 등장
5. 중복 방지 뽑기: 아직 못 모은 요리 중 랜덤, 전부 모으면 전체 랜덤

## 5. AI 기능 기준
- 입력: `goal`(문자열, 비어 있으면 안 됨), `days`(1 이상 정수)
- 처리: 목표 성격 판단 → 논리 순서 → 구체적 행동 문장, 개수 규칙(1~3일 2~3개 / 4~9일 4~6개 / 10~20일 7~9개 / 21일 이상 10개)
- 출력: 순수 JSON 배열 `[{"title": "..."}]` (코드블록·설명 없이)
- 실패 처리: 잘못된 입력은 400, 키/주소 누락 및 API 오류는 500과 안내 문구, 응답 파싱 실패 시 `[ ... ]` 구간 재추출, 프론트는 20초 타임아웃 후 오류 메시지와 재시도 버튼 표시
- 보안: API 키는 서버 환경 변수에만 존재하고 브라우저로 전달되지 않음

## 6. 데이터
서버 DB 없이 브라우저 `localStorage` 의 `jogak-plans` 하나로 관리합니다. 완성 여부는 저장하지 않고 "모든 조각이 체크됐는지"로 그때그때 계산합니다.

## 7. 기술 구성
순수 HTML/CSS/JS + Vercel Serverless(Python) + Codyssey 공개 API(`claude-sonnet-4`), GitHub 연동 자동 배포.
