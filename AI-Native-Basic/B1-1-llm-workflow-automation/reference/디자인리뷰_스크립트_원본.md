**이서연**: 저도 동의해요. 그리고 재고보다 많이 누르면 어떻게 되는 거예요?

**김하늘**: 지금은 그냥 최대치에서 멈추는데, 에러 메시지는 아직 안 넣었어요.

**박준서**: 좋습니다. 그건 확정으로 가죠.

**최민재**: 저는 쿠폰 쪽이 궁금한데, 쿠폰 중복 적용은 되는 건가요?

**이서연**: 그거는 저희가 좀 더 논의해봐야 할 것 같아요. 마케팅팀이랑도 얘기해봐야 하고. 오늘 결론은 못 낼 것 같아요.

**박준서**: 네, 그건 보류로 하고. 다음으로 쿠폰 적용 버튼 위치는 어때요?

**최민재**: 저는 버튼이 가격 요약 위에 있는 게 어색하던데. 순서상 가격 보고 쿠폰 넣는 흐름이 자연스럽지 않나요?
