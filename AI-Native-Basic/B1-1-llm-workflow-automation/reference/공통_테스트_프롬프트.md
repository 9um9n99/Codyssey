# 모델 비교용 공통 테스트 프롬프트

아래 내용을 그대로 복사해서 ChatGPT / Gemini / Claude(또는 선택한 3개 모델) 각각의 새 대화창에 붙여넣으세요.
세 번 다 정확히 동일한 텍스트를 넣어야 공정한 비교가 됩니다.

---

## [복사해서 붙여넣을 프롬프트 시작]

당신은 디자인 리뷰 회의에 참석한 프로덕트 디자이너를 돕는 회의록 정리 도우미입니다.
아래 회의 스크립트를 읽고, 반드시 아래 8개 항목 형식으로 요약해주세요.

**출력 형식 (8항목, 순서대로):**
1. 회의 날짜 / 리뷰 차수
2. 참석자
3. 리뷰 대상 (어떤 화면/시안)
4. 전체 디자인 상태 (승인 / 부분 수정 필요 / 재작업 필요 중 선택)
5. 피드백별 반영 여부 (반영 확정 / 반려 / 추가 논의 필요로 각각 구분)
6. Action Items (담당자, 기한 포함)
7. 이견 / 미합의 지점
8. 다음 리뷰 일정

**규칙:**
- 스크립트에 없는 내용은 지어내지 마세요. 담당자, 기한, 날짜 등이 스크립트에 명시되지 않았다면 "미정" 또는 "스크립트에 명시되지 않음"이라고 표시하세요.
- 발언자가 불분명한 구간이 있다면 특정 인물로 단정하지 말고 "화자 불명"으로 표시하세요.
- 논의는 했지만 결론이 나지 않은 사항은 "반영 확정"이 아니라 "추가 논의 필요"로 분류하세요.

---

**[입력]**

[회의 유형] 디자인 리뷰
[리뷰 차수] 2차 리뷰
[리뷰 대상 화면] 이커머스 장바구니 - 수량 조절 & 쿠폰 적용 UI (v2 시안)
[참석자] 김하늘(프로덕트 디자이너, 발표자), 박준서(디자인 리드), 이서연(PM), 최민재(프론트엔드 개발자)
[스크립트/메모 원문]

김하늘: 오늘은 지난주 1차 리뷰에서 나온 피드백 반영한 v2 시안 보여드릴게요. 장바구니 수량 조절이랑 쿠폰 적용 흐름 위주로 봐주시면 됩니다.

박준서: 좋아요. 일단 수량 스테퍼 버튼부터 볼까요. 지난번보다 커지긴 했는데, 터치 영역이 아직 좀 빡빡한 느낌이에요.

김하늘: 지금 32px인데, 더 키울까요?

박준서: 40px 정도로 가는 게 낫겠어요. 모바일 기준으로.

이서연: 저도 동의해요. 그리고 재고보다 많이 누르면 어떻게 되는 거예요?

김하늘: 지금은 그냥 최대치에서 멈추는데, 에러 메시지는 아직 안 넣었어요.

이서연: 메시지 넣어주세요. "재고 3개까지 담을 수 있어요" 이런 식으로요.

박준서: 좋습니다. 그건 확정으로 가죠.

최민재: 저는 쿠폰 쪽이 궁금한데, 쿠폰 중복 적용은 되는 건가요?

김하늘: 그 부분은 아직 정책이 안 나와서요. 일단 시안에는 쿠폰 1개만 적용되게 그려놨어요.

이서연: 그거는 저희가 좀 더 논의해봐야 할 것 같아요. 마케팅팀이랑도 얘기해봐야 하고. 오늘 결론은 못 낼 것 같아요.

박준서: 네, 그건 보류로 하고. 다음으로 쿠폰 적용 버튼 위치는 어때요?

최민재: 저는 버튼이 가격 요약 위에 있는 게 어색하던데. 순서상 가격 보고 쿠폰 넣는 흐름이 자연스럽지 않나요?

김하늘: 아 그 의견 좋네요. 순서 바꿔볼게요.

(약 3초간 두 사람이 동시에 말해 겹침 - 화자 구분 불가)

화자 불명: 근데 그러면 총 금액 애니메이션도 같이 손봐야 하지 않아요?

김하늘: 네 맞아요, 그것도 같이 볼게요.

박준서: 전체적으로는 방향 좋은 것 같아요. 스테퍼 크기랑 에러 메시지, 버튼 순서 이 세 가지만 수정해서 다시 보여주세요.

이서연: 저는 쿠폰 중복 적용 정책 나오는 대로 다시 공유드릴게요.

김하늘: 네, 알겠습니다. 수정본은 이번 주 안으로 준비해볼게요.

박준서: 좋아요, 오늘은 여기까지 하시죠.
