# GenAI 기초 1: LLM 기반 업무 자동화

**과업**: 디자인 리뷰 미팅 요약 자동화

디자인 리뷰에 참석한 프로덕트 디자이너가 회의 직후 셀프 정리용으로 쓰는 회의록 요약 시스템을 설계했습니다. 3종 이상의 LLM을 비교해 최적 모델을 선정하고, 페르소나 기반 시스템 프롬프트를 설계·개선(v1→v2)한 뒤, 환각 검증과 10턴 대화 로그로 실제 작동을 검증했습니다.

## 핵심 결과 요약

- **모델 선정**: Claude Sonnet 5 (20/20점) — 정확성·형식준수·모호함처리에서 Gemini와 동점이었으나, 어조·가독성과 근거 추적 가능성에서 우위
- **v1→v2 개선**: 처리 순서(4단계) 도입으로 반복 실행 시 판단 흔들림(반영여부 분류, 담당자 표기)이 감소함을 재실행 검증으로 확인
- **환각 검증**: 5문항 전원 Pass
- **10턴 대화**: 조건 변경(3줄 요약 추가), 추가 정보 뒤늦은 제공 두 필수 요소 포함, 전 구간 문맥 유지 확인

## 재현 방법

1. `공통_테스트_프롬프트.md`를 원하는 LLM 웹/앱 새 대화창에 붙여넣어 모델 비교 재현 가능
2. `시스템_설계_문서.md`의 시스템 프롬프트(v2)를 시스템 프롬프트 또는 대화 첫 메시지로 사용해 실제 요약 시스템 재현 가능
3. `10턴_대화_대본.md`를 순서대로 실행하면 실행 로그 재현 가능
