# Codyssey

AI 네이티브 교육 프로그램 Codyssey 과정에서 진행한 과제 모음 레포지토리입니다.

## AI Native Basic

AI 도구 학습 단계에서 진행한 과제들입니다.

| 과제 코드 | 제목 | 설명 |
|---|---|---|
| [B1-1](./AI-Native-Basic/B1-1-llm-workflow-automation) | LLM 기반 업무 자동화 | 디자인 리뷰 회의 요약을 위한 LLM 워크플로우 설계. GPT-5.6, Gemini 3.1 Pro, Claude Sonnet 5 모델 비교 및 할루시네이션 트랩 테스트 스크립트 포함, 10턴 실행 로그 기록 |
| [B1-2](./AI-Native-Basic/B1-2-multimodal-content) | 멀티모달 콘텐츠 제작 | 창원시 마스코트 '피우미' 홍보 영상 제작. 이미지(ChatGPT/GPT-4o), 영상(Kling AI), TTS(Vrew), BGM(Suno), 편집(VITA) 등 멀티모달 도구 활용 및 스토리보드 기획 |
| [B1-3](./AI-Native-Basic/B1-3-nocode-automation) | 노코드 자동화 기초: 워크플로우 설계 | Make와 Zapier를 활용한 노코드 자동화 워크플로우 구축. 채용공고 분류 및 Gmail 뉴스레터 트리거 기반 Slack 자동 게시 프로젝트 |
